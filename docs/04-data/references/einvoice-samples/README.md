# Mẫu XML hóa đơn điện tử tham khảo (`einvoice-samples/`)

Ngày thu thập: `2026-11-26`. Xem báo cáo phân tích đầy đủ và bảng so khớp từng thẻ tại [../../research/einvoice-and-tax.md](../../research/einvoice-and-tax.md).

> **Lưu ý quan trọng:** Toàn bộ 6 file dưới đây đều là **fixture tổng hợp/viết tay từ mã nguồn mở** (không có file nào là hóa đơn sản xuất xuất trực tiếp từ MISA meInvoice, Viettel S-Invoice, VNPT, BKAV, EasyInvoice hay M-Invoice vì các dự án công khai không commit dữ liệu hóa đơn thật). Các file này chỉ dùng để kiểm thử độ chịu lỗi của parser (namespace, UTF-8 BOM, bọc `DLieu`, biến thể thẻ lỗi). **Team vẫn cần bổ sung 2–3 file XML hóa đơn GTGT đầu vào thật đã xóa dữ liệu nhận diện** (có đủ `MSTTCGP`, `DSCKS` ký bởi `NBan` + `CQT`, `MCCQT` 34 ký tự, `THTTLTSuat`, `TTKhac`).
